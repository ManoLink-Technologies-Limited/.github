# ManoLink Technologies Limited

**Software for everyday life in West Africa.** We build payment, commerce and travel products in Freetown, Sierra Leone.

## What we build

| Product | Description |
| --- | --- |
| **Wakarail** | Payment-routing engine that moves money between mobile-money wallets (Orange Money, Afrimoney) through a licensed sponsor. Currently sandbox-only: live money stays disabled until regulatory authorisation, provider agreements and an independent security review are complete. |
| **WakaPay** | The merchant and customer payment experience built on Wakarail. |
| **WakaBots** | Flights, hotels, transport and tours — [wakabots.com](https://wakabots.com). |
| **ChopRank** | Purchase-verified street-food rankings with WhatsApp voting, ordering and delivery. |
| **Mandate Layer** | Recurring mobile-money subscriptions with SMS consent, routed through Wakarail. |
